Prince Tattoos website
======================
index.html is the full public site (one file, no build step).
Upload it to any static host (Netlify, GitHub Pages, cPanel, etc.).

Works anywhere: gallery layout, date picker, WhatsApp booking, Facebook link.
Skrill: set your merchant email in the SKRILL_EMAIL line near the top of the script.

Only works on the claude.ai link (not in this zip):
the owner panel (bookings list, photo/video uploads, settings and Publish).
Outside claude.ai the page shows the public site only, with an empty gallery.
